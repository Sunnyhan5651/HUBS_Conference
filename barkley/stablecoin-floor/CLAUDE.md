# 스테이블코인 발행사의 금리 플로어 운용 최적화

가상자산 공모전 발제안 「디지털 자산의 제도화와 국내 기업의 대응 전략」의 금융공학 파트.

## 최종 범위

**메인 분석은 이 섹션만 따른다.** 아래 다른 섹션의 세부 설계 중 "부록용"으로 표시된 것은 지우지 않고 부록·민감도 분석에만 쓴다.

### 핵심 메시지
1. 발행사는 보유자에게 이자를 줄 수 없다(GENIUS법). 그래서 수익이 거의 전부 준비금 이자이고, **금리 하락이 곧 적자 위험**이다.
2. 금리가 내릴 때 발행량이 늘어나는 **자연 헤지는 작다** (`02_supply_regression.ipynb` 10번 섹션: 3년간 금리 4%→2%일 때 이자수익 −26%, 자연 헤지로 메워지는 몫은 +3~6%p).
3. 플로어 **최적 운용 정책**을 효율적 투자선으로 찾는다.
4. 지금은 플로어가 싸다 → **만기 선택이 중요**하고, **작은 발행사에게는 비싸다**.

### 메인 분석 설정

| 항목 | 설정 |
|---|---|
| 금리 | **시장 일치 모형 하나만.** r(t) = f(0, t) + x(t). f(0, t)는 현재 선도금리, x(t)는 평균 0으로 회귀하는 Vasicek 충격 dx = −a·x·dt + σ·dW (a = 0.093, σ = 0.64, x(0) = 0) |
| 곡선 | 미국채 곡선에서 **단기 국채 − SOFR 차이를 곡선 전체에서 빼는** 간단 보정, **PCHIP 보간**. 보정 폭은 1개월 국채 − SOFR (2026-10-26 기준 18bp → 첫 달 선도금리 = SOFR). `04_floor_pricing.ipynb` |
| 발행량 | b1 = 0, **성장률 g = 0** (R 고정), 점유율 고정. 최근 24개월 평균(연 30%)은 비교용 한 줄로만. 이유: 손실확률 기준은 성장이 멈춘 경우를 봐야 하고, 최근 24개월은 인하기·GENIUS법이 겹친 특수 시기 |
| 준비금 수익률 | **max(r, 0) − 0.15%p** (Circle 실제 준비금 수익률이 기준금리보다 0.1~0.2%p 낮았던 검증 결과) |
| 거래비용 | 명목금액 대비 **연 2bp** |
| 전략 (25개) | 무헤지 + K 4개 × **h(1 − s ≈ 37.5%, 50%, 100%)** × 만기(1년 롤링, 3년). **K는 규모마다 r* − 1%, r* − 0.5%, r*, r* + 0.5%** |
| 평가 | **"3년 중 한 해라도 연간 적자"인 경로의 비율**(손실확률), 총 헤지 비용(보험료·거래비용 구분). 3년 누적 손익 기준은 참고용 |
| 규모 | 발행사 3개를 r*로 정의: **신규 진입 r* = 4.5%, Circle 수준 r* = 3.6%(실제 Circle 값), 대형 r* = 2.5%**. C·s는 Circle 값 그대로 두고 R만 역산 |

- 시장 일치 모형에서는 경로의 평균이 선도금리와 같으므로, **시나리오와 플로어 가격의 기준이 일치**한다. (Vasicek b를 따로 정할 필요가 없다)
- 음수 금리 처리는 그대로: 경로·정산은 모형대로, 이자수익만 max(r, 0).
- **고정비 C = 9.62억 달러/년, 배분율 s = 0.625** (확정). Circle 상장 이후 최근 4개 분기(2025-Q3 ~ 2026-Q2) SEC XBRL 합계. C = 영업비용(주식보상 포함), s = 유통·거래 비용 ÷ 준비금 이자. 유통·거래 비용은 총수익 − 영업비용 − 영업이익으로 역산. `01_data_collection.ipynb` 3번 섹션, `data/processed/circle_params.csv`
- **플로어 가격 σ = 등가 σ** (확정): 바슐리에에 플로어렛마다 σ_eq(T) = σ·√((1 − e^(−2aT)) / (2aT)) (σ 0.64, a 0.093 → 1년 0.61, 3년 0.56). 시장 일치 모형의 퍼짐과 정확히 같다. `src/floor_pricing.price_floor(..., a=0.093)`. σ 0.64 고정 가격표(31~80% 더 비쌈)는 부록용

## 연구 질문

달러 스테이블코인 발행사는 금리 플로어를 어떻게 운용해야, **3년 누적 손실확률을 5% 이하**로 유지하면서 **헤지 비용(프리미엄)을 최소화**할 수 있는가?

```
min 프리미엄  (K, h, T 선택)
s.t. P(π_3y < 0) ≤ 5%
```

## 핵심 기호

| 기호 | 의미 |
|---|---|
| r | 시장금리 (기준: SOFR) |
| R | 준비금 규모 = 스테이블코인 발행량 |
| C | 연간 고정비 |
| s | 유통파트너 배분율 (Coinbase 등에 주는 준비금 수익 비중) |
| π | 이익 = (1 − s)·r·R − C |
| r* | 손익분기 금리 = C / R (배분율 반영 시 C / ((1 − s)·R)) |
| K | 플로어 행사가 |
| N, h | 플로어 명목금액, 헤지 비율 h = N / R |
| T | 플로어 만기 (1년 롤링 vs 3년 등) |

## 전체 단계

1. **데이터 수집** — 금리·USDC·통제변수·Circle 재무제표 완료
2. 금리 모형 (Hull-White 또는 Vasicek 파라미터 추정) — `03_rate_model.ipynb`에서 Vasicek 추정·검증·시험 시뮬레이션
3. 발행량 모형 (USDC 발행량 추세 + 금리와의 관계) — 회귀·자연 헤지 크기(`02_supply_regression.ipynb`) 완료. 메인은 b1 = 0, g = 0으로 시뮬레이션에 반영
4. 플로어 가격 산출 (블랙 / 바슐리에) — `04_floor_pricing.ipynb`에서 국채 곡선 + 바슐리에 가격표 (함수는 `src/floor_pricing.py`)
5. 전략 후보 정의 (무헤지, K·h·T 조합, 칼라, 리시버 스왑)
6. 몬테카를로 시뮬레이션 (3년 누적 이익 분포) — `05_simulation.ipynb`에서 최종 범위 설정으로 실행 (5~8단계 포함). 결과(g = 0, 한 해라도 적자 기준): 신규 진입 r* 4.5% 무헤지 90% → 5% 달성 전략 없음 / Circle 수준 r* 3.6% 무헤지 16.5% → 최적 K 4.1%·h 37.5%·3년 (0%, 0.88억 달러, R의 연 4.1bp) / 대형 r* 2.5% 무헤지 0.8% → 무헤지. 1년 롤링은 2·3년차 적자가 남아 3년 만기보다 크게 불리
7. 평가 (손실확률, 비용, 기대이익, 최악 5% 평균)
8. 효율적 투자선 + 5% 기준으로 최적 정책 선택
9. 규모 분석: R을 바꿔가며 플로어가 효율적이 되는 임계 규모 도출 — 최종 범위에서는 규모 3개(r* 4.5 / 3.6 / 2.5%)로 대신함. 연속 임계 규모 도출은 하지 않음(제안으로만)
10. 한계 점검 (모형 위험, 유동성, 거래상대방, 베이시스 위험) — `06_robustness.ipynb`에서 강건성 점검: Circle 수준 결론 ①~④가 8개 설정 중 7개에서 유지 (σ 0.32에서만 ① 무헤지 > 5%가 뒤집힘). a의 95% 신뢰구간이 0 포함. 1차 설정 변경 이력은 06 끝 부록 셀. 엔진은 `src/issuer_sim.py`. 한계 정리는 `output/limitations.md`
11. **마무리 (HANDOFF Phase 1~6 완료, 2026-10-30)** — 전략 25개(h 37.5·50·100%)로 05·06 갱신, 발제안용 그래프 `07_final_figures.ipynb` → `output/figures/final/`, 결과물 `output/report.md`, `one_pager.md`, `qna.md`, `limitations.md`, 프로젝트 안내 `README.md`

> 메인 분석의 전략·평가·규모는 맨 위 "최종 범위"를 따른다. 칼라·리시버 스왑 전략, 기대이익·최악 5% 평균 평가는 부록용.

## 2단계 금리 모형 설계

> **부록용 (세계 B·C).** 메인은 "최종 범위"의 시장 일치 모형이다. 아래에서 메인에도 그대로 쓰는 것은 **a = 0.093, σ = 0.64 추정값과 음수 금리 처리**뿐이다. 장기 평균 b(기본 FOMC 3.2% = 세계 B, 스트레스 1.32% = 세계 C)와 σ 0.32 민감도는 부록용이다.

시나리오 생성용 Vasicek 모형 `dr = a(b − r)dt + σdW`. 근거는 `03_rate_model.ipynb`(월평균 기준금리, 2000-01 ~ 2026-09, AR(1) 추정). 함수는 `src/rate_model.py`.

| 파라미터 | 기본 | 민감도·스트레스 | 근거 |
|---|---|---|---|
| a (평균회귀 속도) | 0.093 (반감기 약 7.5년) | — | 2000년~ 추정값 유지 |
| b (장기 평균) | **FOMC 장기 정책금리 전망 중위값** (FRED `FEDTARMDLR`, 최신 값 사용: 2026-09-16 발표 3.2%) | 스트레스: 과거 추정치 **1.32%** | 아래 |
| σ (변동성) | **0.64** (2000년~ 장기) | 민감도: **0.32** (최근 3년) | 아래 |

- **b를 FOMC 전망으로 하는 이유**: 과거 평균 1.32%는 제로금리 약 9년에 끌려 내려간 값이다. 시장 선도금리와 차이가 크면 시나리오(금리 하락 예상)와 가격(선도금리 기준) 사이에 괴리가 생겨 플로어가 인위적으로 싸 보인다.
- **σ를 장기 값으로 하는 이유**: 플로어가 막으려는 급락 위험(2008, 2020)을 담아야 한다. 시나리오와 가격의 σ가 다르면 플로어가 인위적으로 싸거나 비싸 보이므로 **시나리오와 플로어 가격 계산에 같은 σ**를 쓴다.
- 시작 금리 r0: 최신 SOFR
- 월말 값 대신 월평균을 쓴다. 월말 SOFR 튐 때문에 월말 값으로 추정하면 σ가 0.92로 부풀려진다.
- **음수 금리**: 금리 경로와 플로어 정산은 모형 그대로(음수 허용), **발행사 이자수익 계산에서만 max(r, 0)** 을 쓴다. 현재 설정에서 3년 안 음수 경로 확률은 0.1% 미만.
- 한계: AR(1)은 φ가 1에 가까울 때 평균회귀를 빠르게 잡는 경향이 있다. 1요인 모형이라 기대 선행·기간 프리미엄을 담지 못한다.

## 3단계 발행량 모형 설계

시뮬레이션에서 준비금 R(USDC 유통량)을 월 단위로 만드는 규칙. 근거는 `02_supply_regression.ipynb`(2020-05~2026-09 월간 회귀).

> 메인은 "최종 범위"대로 **b1 = 0, g = 0, 점유율 고정, 점프 없음**이다. 아래에서 b1 기본·낙관, 성장률 기본(최근 24개월, 비교용 한 줄)·중간, 2년물 연결(b1 ≠ 0일 때만 필요), 점프 위험은 **부록용**이다.

### 구조

```
Δlog(USDC 제외 시장)_t = g + b1·Δy_2Y,t
R_t = R_{t-1} · exp(Δlog(USDC 제외 시장)_t) · (1 + J_t)
```

- 점유율은 고정 → 점프가 없는 달에는 R의 성장률 = USDC 제외 시장의 성장률
- J_t: 발행사 고유 충격 (아래 3번). 충격이 없는 달은 0
- 비트코인 항(b2)과 시장 충격 더미(b3)는 시뮬레이션에 넣지 않음 (비트코인 경로를 따로 만들지 않기 때문)
- 미정: 매달 오차항(잔차 변동성)을 넣을지. 참고로 최근 24개월 월간 성장률의 표준편차는 0.029

### b1 시나리오 (02 노트북 결과)

| 시나리오 | b1 | 근거 |
|---|---|---|
| 보수 (**메인**) | 0 | 메인 결론 기준: 95% 신뢰구간이 0을 포함(상한 +0.004 ≈ 0) |
| 기본 (부록용) | −0.039 | 메인 회귀 추정값 (HAC 표준오차 0.022, p=0.076) |
| 낙관 (부록용) | −0.083 | 95% 하한, 자연 헤지가 가장 강한 경우 |

- 근거: 9개 설정 모두 b1이 음수다. p값은 메인·전체 시장·기준금리 설정에서 0.06~0.10으로 경계 수준이다. 2022년 이후만 쓰면 −0.012로 약해진다.
- **최적 정책은 b1 = 0(보수) 시나리오로 결정한다.** 손실확률 기준에서는 자연 헤지를 기대하지 않는 b1 = 0이 가장 보수적이기 때문이다. 기본·낙관은 민감도 분석으로 쓴다.

- 상수 a(월 0.045)는 쓰지 않는다. 2020~21년 급성장기 때문에 커진 값이고, 2023년 이후 잔차가 대부분 음수(과대 예측)다.

### 1. 2년물 변화 계산 (부록용: b1 ≠ 0일 때만 필요)

- **Δ2년물 = 0.5 × Δ단기금리** (데이터 기울기). 2018-05 ~ 2026-09 월평균 데이터에서 Δ2년물을 ΔSOFR로 회귀한 기울기가 1개월 0.45, 3개월 0.56, 12개월 0.52였다.
- 한계: 모형 공식과 어긋난다. Vasicek 채권가격 공식으로는 y_2Y = (−ln A(2) + B(2)·r) / 2, B(τ) = (1 − e^(−aτ)) / a 이므로 Δy_2Y = (B(2)/2)·Δr = **0.91**·Δr 이다. 데이터 기울기의 95% 신뢰구간(상한 약 0.69~0.74)도 0.91에 닿지 않는다. 1요인 모형이 2년물의 "기대 선행"(2년물이 기준금리보다 먼저 움직임: 월간 변화 상관 약 0.2, 의미 있게 움직인 달 비율 기준금리 35% vs 2년물 68%)을 담지 못하기 때문이다. 모형 공식을 쓰면 자연 헤지를 약 2배 과대평가한다.
- b1 = 0(보수) 시나리오에는 영향이 없다.

### 2. 성장률 g (상수 a 대신)

### 3. 발행사 고유 충격 (점프) — 부록용

- 점유율은 기본적으로 고정하되, 발행사 고유 충격을 점프로 추가한다. 충격이 나면 R ← R × (1 + J)
- 기본값: 연 발생확률 약 1/3 (월 확률 = 1 − e^(−1/36) ≈ 2.7%), 충격 크기 J = −30%
- 민감도: 점프 없음 / 기본 / 빈도 2배 (연 약 2/3)
- 근거 데이터 (`usdc_rates.parquet`, 점유율 = USDC ÷ 전체 시장)

| 사례 | 구간 | USDC 점유율 | USDC 유통량 | USDC 제외 시장 |
|---|---|---|---|---|
| 바이낸스 자동전환 | 2022-09-28 → 10-31 | 32.2% → 29.5% (−8.4%) | −11.3% | +0.7% |
| SVB 디페깅 | 2023-03-09 → 03-31 | 32.1% → 24.7% (−22.9%) | −24.5% | +8.5% |

## 작업 방식 (중요)

- 사용자는 경제·금융 복수전공 3학년, 파생상품 기초는 탄탄하지만 **수학과 코딩은 아직 익숙하지 않다.** 이 프로젝트로 데이터 수집·분석을 배우고 싶어한다.
- **주피터 노트북으로 단계별로** 진행한다. 한 셀에 한 가지 일만 하고, 셀마다 위에 마크다운으로 "이 셀이 하는 일"을 쉬운 한국어로 적는다.
- 코드 주석과 설명은 **최대한 쉬운 한국어**로. 전문용어는 처음 나올 때 한 줄로 풀어서 설명한다.
- 수식은 결과를 해석하는 데 필요한 만큼만 쓰고, 항상 직관적인 의미를 함께 적는다.
- 원본 데이터는 `data/raw/`에 받은 그대로 저장하고, 가공은 별도 단계에서 한다.
- 데이터를 받으면 기간, 결측치, 이상값을 먼저 확인하고 간단한 그래프로 보여준다.
- 그래프 제목과 축 이름은 한국어로 (한글 폰트 설정 포함).
