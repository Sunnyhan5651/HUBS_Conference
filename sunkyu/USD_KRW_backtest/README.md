# USD/KRW 이벤트 드리븐 백테스트

**디지털 자산 제도화 이벤트가 원/달러 환율에 미치는 영향 분석**

---

## 연구 배경

barkley 팀의 분석 결과, 디지털 자산 제도화 이벤트가 미국 국채 금리에는 통계적으로 유의한 영향을 주지 않는 것으로 나타났다 (`barkley/README.md`). 이에 본 분석은 **"미국 금리보다 USD/KRW 환율 채널을 통한 국내 전이 가능성"** 을 검증한다.

가설: 긍정적 제도화 이벤트 → 위험선호 심리 → 원화 강세(DEXKOUS 하락) → 방향 조정 AR > 0

## 방법론

### 이벤트 스터디 (Event Study)

```
추정 창: [t0 − 126, t0 − 6]  → 120 거래일
이벤트 창: [-5, +5] (메인) / [-1, +1] (보조)
정상 수익률: 추정 창 평균 수익률 (Constant Mean Return Model)
AR(t) = r(t) − μ_est
```

> USD/KRW는 주가처럼 단일 팩터에 명확히 귀속되지 않아 시장 모형보다 단순 평균 모형이 일반적으로 선호됨

### 방향 조정

이벤트 방향 `+1`(긍정) / `-1`(부정)을 고려한 가설 검정:

```
Dir-Adj AR = AR × (−direction)
```

긍정 이벤트에서 원화 강세(DEXKOUS↓, AR < 0)라면 Dir-Adj AR > 0 → 가설 지지

### 통계 검정

| 검정 | 설명 |
|------|------|
| **BMP 검정** | Standardized AR (sAR = AR / σ_est) 기반, 분산 이분산 강건 |
| **부호 검정** | 양수 AR 비율의 이항검정 (H₀: 50%) |
| **Placebo 검정** | 2,000회 무작위 날짜 추출 → 실제 CAAR 백분위수 산출 |

### 오염 판정 (±2 거래일)

- **FOMC / CPI**: xlsx `매크로 일정 겹침` 컬럼 파싱
- **BOK 기준금리 변경**: ECOS 422Y001 diff > 0.01%p 탐지
- 오염 이벤트 포함한 **전체 표본** vs 제외한 **clean 표본** 비교

## 분석 결과 (Main 22건, 2015–2026)

### 핵심 결론

> **디지털 자산 제도화 이벤트는 원/달러 환율에 통계적으로 유의한 영향을 주지 않는다.**

barkley 팀의 미국 국채 금리 분석과 동일하게, 환율 채널에서도 유의한 전이 효과가 발견되지 않았다.

### 이벤트 당일 (t=0) 결과

| 윈도우 | 유효 N | AAR | BMP t | p값 | 유의 |
|--------|--------|-----|-------|-----|------|
| [-5,+5] | 22건 | -0.09% | -0.65 | 0.52 | ✗ |
| [-1,+1] | 22건 | -0.09% | -0.64 | 0.53 | ✗ |

두 윈도우 모두 p > 0.5 — 이벤트 당일 환율에 체계적인 반응이 없다.

### 방향 조정 분석

"긍정 이벤트 → 위험선호 → 원화 강세(DEXKOUS↓)" 가설 검정:

| 윈도우 | Dir-Adj AAR(t=0) | BMP t | p값 |
|--------|-----------------|-------|-----|
| [-5,+5] | -0.009% | -0.23 | 0.82 |
| [-1,+1] | -0.012% | -0.23 | 0.82 |

방향까지 고려해도 유의하지 않다. 긍정 이벤트에서 원화 강세 패턴이 존재하지 않는다.

### Placebo 검정

| 구분 | CAAR |
|------|------|
| 실제 이벤트 | +0.21% |
| 무작위 날짜 평균 | -0.03% |
| p값 | **0.54** |

실제 이벤트 효과가 무작위 날짜 추출과 구별되지 않는다. 이벤트 자체에 정보 효과가 없음을 확인한다.

### 오염 제외 비교 ([-1,+1], t=0)

22건 중 13건이 FOMC/CPI와 겹쳐 오염으로 분류된다.

| 표본 | N | AAR | t값 | p값 |
|------|---|-----|-----|-----|
| 전체 | 22건 | -0.09% | -0.64 | 0.53 |
| 오염 제외 | 9건 | +0.04% | +0.37 | 0.72 |

오염 이벤트를 제거해도 유의하지 않다. 매크로 이슈가 결과를 왜곡하고 있지 않다.

### t+2 단순 유의성에 대한 주의

[-5,+5] 창에서 t+2 시점이 BMP p=0.014로 유의하게 나타났으나:

- **부호검정 p=0.13** → AR 양수 비율이 50%를 의미있게 초과하지 않음
- 11개 시점 동시 검정 → 다중검정 문제로 우연히 하나가 유의할 수 있음
- 경제적 해석 불명확 (왜 t+2인가?)

→ **통계적 노이즈로 해석**하는 것이 적절하다.

### barkley 결과와의 종합

```
[barkley]  제도화 이벤트 → 미국 국채 금리 반응?  → 없음 (전 만기 p > 0.34)
[sunkyu]   제도화 이벤트 → USD/KRW 반응?         → 없음 (t=0 p > 0.52)
```

> **"디지털 자산 제도화 충격은 전통 금융 시장(금리·환율)으로 전이되지 않는다"**
> — 2015~2026년 이벤트 기준, 크립토 시장은 전통 금융과 분리(decoupled)된 상태

### 기업 전략 시사점

- 크립토 제도화 이벤트를 근거로 단기 환율·금리 헤징 포지션을 취할 근거가 **현재는 약함**
- 단, 제도화가 심화될수록 전이 채널이 형성될 수 있어 지속적인 모니터링 필요
- 국내 기업의 디지털 자산 편입 타당성은 거시 변수 전이보다 **직접적 자산 수익성·리스크** 측면에서 접근해야 함
