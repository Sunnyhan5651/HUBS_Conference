# 무기한선물(Perpetual Futures) 이벤트 드리븐 백테스트

**디지털 자산 제도화 이벤트가 BTC·ETH 무기한선물 시장에 미치는 영향 분석**

---

## 연구 배경

선행 분석에서 제도화 이벤트가 전통 금융 시장(금리·환율·주가·채권) 전 채널에서 유의한 충격을 주지 않는 것으로 나타났다. 본 분석은 **크립토 파생상품 시장 자체**가 제도화 이벤트에 반응하는지를 추가 검증한다.

특히 무기한선물의 **펀딩 레이트(Funding Rate)** 는 레버리지 투기 심리를 직접 반영하는 지표로, 긍정적 제도화 이벤트가 시장의 낙관론·롱 포지션 수요를 유발하는지 측정한다.

```
[barkley]    제도화 이벤트 → 미국 국채 금리 반응?       → 없음
[sunkyu1]    제도화 이벤트 → USD/KRW 반응?               → 없음
[sunkyu2]    제도화 이벤트 → KOSPI·KOSDAQ·국고채 반응?   → 없음
[sunkyu3]    제도화 이벤트 → VIX·S&P500·NASDAQ 반응?     → 없음
[sunkyu4]    제도화 이벤트 → BTC·ETH 무기한선물 반응?    → 본 파일
```

### 펀딩 레이트 구조

Binance는 8시간마다(00:00, 08:00, 16:00 UTC) 롱·숏 포지션 간 펀딩을 정산한다.

```
일별 펀딩 레이트 = 하루 3회 정산값의 합 (%)
긍정 이벤트 가설: 제도화 이벤트 → 롱 수요 증가 → 펀딩 레이트 상승
```

- Main 표본: 22건 중 **21건** 유효 (2017-12월 이벤트 1건은 Binance perp 출시 이전)
- Robust 표본: 49건 중 **43건** 유효

## 방법론

### 이벤트 스터디

```
추정 창: [t0 − 126, t0 − 6]  → 120 거래일
이벤트 창: [-5, +5] (메인) / [-1, +1] (보조)
정상 수익률: Constant Mean Return Model
AR(t) = actual(t) − μ_est
```

### 방향 조정

| 자산 | 가설 | 방향 조정 |
|------|------|----------|
| BTC·ETH 펀딩 레이트 | 긍정 이벤트 → 롱 수요 → 펀딩 레이트 상승 | `dir_adj = AR × (+direction)` |
| BTC 선물 수익률 | 긍정 이벤트 → 선물 가격 상승 | `dir_adj = AR × (+direction)` |

### 통계 검정

| 검정 | 설명 |
|------|------|
| **BMP 검정** | Standardized AR (sAR = AR / σ_est) 기반, 이분산 강건 |
| **부호 검정** | 양수 AR 비율의 이항검정 (H₀: 50%) |
| **Placebo 검정** | 2,000회 무작위 날짜 → 실제 CAAR 백분위수 |

### 오염 판정 (±2 거래일)

FOMC / CPI가 이벤트 창 ±2 거래일 이내 → 오염 이벤트 분류
Main 21건 중 **13건(62%) 오염** — 타 백테스트 대비 오염율 높음

## 결과 해석

### 방향은 일치하나 통계 유의성 없음

AAR 부호가 일관되게 양수(+)로, "긍정 이벤트 → 펀딩 레이트 소폭 상승" 방향 가설과 일치한다. 그러나 BMP t-통계량이 모두 0.5 미만으로 신호 대비 노이즈가 압도적으로 크다.

### Robust 표본 확대 시 신호 희석

Main 21건에서 AAR +0.013%였던 BTC 펀딩 레이트가 Robust 43건에서 +0.005%로 감소한다. Robust 추가 이벤트(채택·신뢰충격 등)가 이질적 방향성을 섞어 신호를 희석시킨다.

### 높은 오염율이 검정력 제한

Main 21건 중 13건(62%)이 FOMC·CPI와 겹쳐 Clean 표본이 8건에 불과하다. 신호 부재가 "실제 무반응"인지 "검정력 부족"인지 구별이 어렵다는 점을 한계로 명시해야 한다.

### 크립토 시장 무반응의 세 가지 해석

**① 빠른 가격 선반영**
암호화폐 시장은 24/7 거래되며 정보 반응 속도가 매우 빠르다. "미국 주식 t0" 기준의 이벤트 창 설정이 이미 아시아·유럽 시간대에 반영된 이후일 수 있다. 일봉 단위 분석은 당일 내 반응을 포착하지 못한다.

**② 이벤트 이질성에 의한 신호 상쇄**
긍정 이벤트(ETF 승인)와 부정 이벤트(규제 강화)가 혼재하며, 이벤트별 시장 반응 강도도 크게 다르다. 방향 조정 후에도 유의성이 없다는 점은 이벤트 분류 자체의 노이즈를 시사한다.

**③ 펀딩 레이트의 평균회귀 특성**
펀딩 레이트는 8시간마다 재설정되며 극단값은 빠르게 평균으로 회귀한다. 이벤트 당일 스파이크가 발생해도 일봉 집계에서 소멸될 수 있다.

```
채널                         결과

USD/KRW                      → 무반응 [sunkyu1]
KOSPI / KOSDAQ               → 무반응 [sunkyu2]
국고채 3Y / 10Y              → 무반응 [sunkyu2]
VIX                          → 무반응 [sunkyu3]
S&P 500 / NASDAQ             → 무반응 [sunkyu3]
BTC 펀딩 레이트              → 무반응 [sunkyu4]
ETH 펀딩 레이트              → 무반응 [sunkyu4]

───────────────────────────────────────────────────
전통 금융 + 크립토 파생 11개 변수 전체 무반응
```

> **"크립토 제도화 충격은 전통 금융 시장은 물론, 크립토 파생상품 시장에서도 일봉 단위로 체계적으로 식별되지 않는다."**
> — 2019–2026년 Binance 무기한선물 데이터 기준

### 기업 전략 시사점

- 제도화 이벤트 타이밍에 맞춰 단기 무기한선물 포지션을 취하는 전략은 현재 데이터 기반으로 통계적 근거가 없음
- 크립토 파생 시장도 무반응이라는 점은 제도화가 아직 레버리지 투기 수요를 체계적으로 자극하지 않음을 시사
- 향후 현물 ETF 자금 유입 확대·기관 참여 증가에 따라 펀딩 레이트 채널이 형성될 가능성 → 지속적 모니터링 필요
- 기업의 디지털 자산 편입 전략은 이벤트 타이밍 트레이딩보다 **중장기 포트폴리오 분산** 관점에서 접근해야 함
